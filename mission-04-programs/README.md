## Task 4.2: Compiler vs interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Translates the entire source code into machine code or another executable form before execution. | Translates and executes the program as it runs, typically one statement or unit at a time. |
| Typical output | Often produces an executable file or compiled code. | Usually executes the program directly without creating a separate standalone executable. |
| One example | C compiler (GCC). | Python interpreter. |
| One advantage | Compiled programs can execute quickly because translation has already happened. | Makes testing and debugging easier because code can be run interactively and errors can be identified during execution. |

**Explanation:** A compiler translates the entire program into machine code or another executable form before the program runs. An interpreter executes the program while translating its instructions during execution. Compilers often produce an executable file, whereas interpreters generally run the code without creating a separate executable. Python is commonly used as an example of an interpreted language, while C is commonly used as an example of a compiled language.
